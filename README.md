# zhenghuabao.github.io

Personal homepage of [Zhenghua Bao (包正华)](https://zhenghuabao.github.io), AI Research Engineer at FlashLabs.

Single-file static site, no build step. Push `index.html` to `main` and GitHub Pages serves it.

## Stack

Hand-written HTML + CSS in one file. System fonts, no webfonts, no JavaScript, no
external requests. Light and dark themes follow `prefers-color-scheme`.

## Adding a portrait

Drop a square image at `photo.jpg` and uncomment the `<img class="portrait">` in
the masthead. 600x600 or larger renders crisply on retina displays.
